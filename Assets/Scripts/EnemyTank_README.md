# Настройка танков

Все боевые враги в Tutorial, level1, level2 и level3 — экземпляры
`Assets/Prefabs/EnemyTank.prefab`, включая бывшие Ricochet Enemy. Учебные мишени
во второй комнате Tutorial сохранены отдельно без стрельбы, с 1 HP.

## Общие параметры врагов

Открой EnemyTank.prefab двойным щелчком в Project. Изменения префаба применяются
ко всем экземплярам, кроме параметров, переопределённых в конкретной сцене.

На корневом объекте, компонент Tutorial Robot:

- First Shot Delay: базовая реакция при каждом обнаружении игрока, сейчас 0,8 с.
- Reaction Offset: добавочная задержка конкретного врага. У соседних врагов
  сохранён небольшой разброс, уменьшенный на 20% вместе с базовой реакцией.
- Shot Interval: перезарядка, оставлена 2,1 с.
- Sight Range: дальность зрения, 16 юнитов.
- Sight Angle: полный угол сектора зрения, 150 градусов.
- Turret, Muzzle, Bullet Prefab: башня, точка появления пули и Ball.prefab.
- Player и Level: ссылки на сцену. Для нового экземпляра находятся автоматически.
- Room Index: индекс комнаты с нуля; уточняется при старте по списку Targets.

Компонент Tutorial Target:

- Max Health: максимальное здоровье, 5 по умолчанию.
- Shielded: наличие щита. Щит поглощает урон до попадания красного рикошета.
- Shield Visual: объект отображения щита; видимость синхронизируется при старте.

Для настройки одного врага выбери его в Hierarchy и измени поля в Inspector.
Чтобы вернуть общий параметр, используй Revert для этого override.
Reaction Offset и наличие щита — намеренные отличия отдельных экземпляров.

## Расстановка нового врага

Для щитового врага используй `Assets/Prefabs/ShieldedEnemy.prefab`: Shielded
включён, Shield Visual ссылается на дочерний Red Shield. Круг щита имеет свой
Circle Collider 2D, поэтому попадания в его край тоже регистрируются. Красный
рикошет снимает щит вместе с коллайдером; здоровье этим попаданием не уменьшается.
Следующее рикошетное попадание наносит 5 урона. В Room 3 сцены level2 оба щитовых
врага используют этот префаб.

Перетащи EnemyTank.prefab внутрь нужного Room. Добавь его Tutorial Target в
`Tutorial Level → Rooms → нужная комната → Targets`, чтобы работали активация,
ворота и чекпоинт. Поверни дочерний Turret: его направление задаёт сектор зрения.

## Внешний вид

- `Assets/Sprites/EnemyTank.png`: красно-оранжевый корпус вместе с гусеницами.
- `Assets/Sprites/PlayerTank.png`: зелёный корпус вместе с гусеницами.
- Дочерний Hull / Sprite Renderer задаёт спрайт корпуса.
- У врага Hull редактируется в префабе, у игрока — в каждой сцене.
- Turret вращается отдельно; его рисунок и Barrel можно менять независимо.
- Muzzle задаёт место выхода пули. Box Collider 2D на корне задаёт столкновения.

## Пули и игрок

В Ball.prefab, компонент Bullet: Speed, Radius и Lifetime.
В Bullet.cs: MaxReflections — лимит 5 отражений.
В TutorialTarget.cs / Hit: прямой урон 1, рикошетный 5.
На игроке Tank Movement: Move Speed, Turn Speed и Shot Interval.

Спрайты созданы встроенным imagegen на прозрачном фоне. Промпт врага: корпус танка
строго сверху, направлен вверх, две встроенные тёмные гусеницы, красно-оранжевая
броня, без башни и ствола, читаемый компактный силуэт. Промпт игрока: сохранить
силуэт, ракурс, детали и прозрачность врага, заменить броню на изумрудно-зелёную.
