# Первый уровень: комнаты 1.1, 1.2, 1.3

Открыть `Assets/Scenes/Level1Rooms.unity` или в главном меню выбрать «Играть» и зелёную кнопку первого уровня.

WASD / стрелки — движение. Правая дверь ведёт в следующую комнату, левая — в предыдущую. Между комнатами плавное чёрное затемнение. В третьей комнате перехода на второй уровень пока нет.

Esc / кнопка меню — окно выхода: «Да» возвращает в главное меню, «Нет» и крестик продолжают игру.

В комнатах установлены препятствия из Figma: 1.1 — пирамида и блоки; 1.2 — сундук и два зеркала; 1.3 — красное зеркало, синее зеркало и блоки. Каждый объект находится в группе `Figma Obstacles` и имеет коллайдер. Враги пока не добавлены. Игрушки по краям нарисованы в исходном фоне Figma. Сердца и таймер — декоративные элементы макета, пока без игровой логики.

Источники: Figma Ph3GGyRnJoW5mYfM8ddWyI, верхние фреймы 1.1 (56:3026), 1.2 (56:3048), 1.3 (56:3069). PNG с этими ID — полные референсы. Фоны комнат: 56:3027, 56:3049, 56:3070. HUD: 56:3028, 56:3029, 56:3035. Танк: 56:3036.

Скорость и длительность затемнения меняются в компоненте `FirstLevelRooms`. Фоны лежат в объектах `Room 1.1`, `Room 1.2`, `Room 1.3`.

Меню Unity `Bounce Club/Build First Level Rooms` пересобирает эту сцену. `Bounce Club/Preview First Level` сохраняет изображение рядом с папкой проекта.

Границы задаются в `BuildFirstLevelRooms.AddBoundaries` по пиксельным координатам исходного фона 1512 × 1008. `Bounce Club/Preview Room Boundaries` выводит изображение с контурами. `Bounce Club/Verify Room Boundaries — Five Passes` проверяет все три комнаты пять раз: подход к стенам и углам, обратное движение, восстановление после пересечения и оба прохода. Перед запуском этих команд остановить Play Mode.

Во второй комнате сундук расположен по центру пола и уменьшен до 70% вместе с коллайдером. Проверка границ включает маршруты от левой двери до правой сверху и снизу сундука, по пять повторений.

Красное игровое зеркало — Figma image 70, узел 56:3404, расположенный отдельно на странице у нижней части комнаты 1.3. Исходный PNG RedMirrorGame.png, позиция точки отражения (-0.54, -2.98), наклон -4.0171 градуса. Синее зеркало: точка (0.05, 1.2), наклон +21.15599 градуса. Цепочка: выстрел вниз в красное зеркало → вверх к синему → будущий босс. Пока установлены объекты с коллайдерами; стрельба не подключена. MirrorRicochetSurface задаёт плоскую нормаль и рассчитывает отражённое направление; траектория проверяется на попадание в точку будущего босса (3.848, -1.948) и отсутствие препятствий для снаряда радиусом 0.035. Выстрел вниз начинается с X=-0.54. Gizmos выбранной Room 1.3 показывает цепочку; меню Bounce Club/Preview Ricochet Route сохраняет схему..

RoomEdgeBlend.shader плавно сводит цвет внешних краёв фоновых спрайтов к цвету камеры. Карта и текстуры внутри не изменены.

Масштаб карты задаёт FirstLevelCameraFit: minimumHalfHeight=5.15, horizontalHalfWidth=8.2, verticalOffset=0.4315. На узком Game View карта больше примерно на 17%, на 16:9 — примерно на 5%. Карта дополнительно опущена на 40 пикселей при высоте Game View 1080; нижняя рамка расположена близко к краю экрана. Масштабы объектов, коллайдеры и углы рикошета сохранены.

Текстуры первого уровня заменены изображениями из исходных растров Figma. TextureQuality.json хранит ссылки imageRef, размеры и плотность спрайтов. Для объектов используется PPU=400 вместо 100: размеры в сцене сохраняются при увеличении разрешения PNG. Фоны взяты из исходного изображения 1536×1024 с PPU=101.5873016, что сохраняет прежний размер 15.12×10.08. Исходный фон ограничен этим разрешением; увеличение PNG не добавляет деталей. Сжатие и mipmaps отключены. Level1TextureQuality сохраняет эти настройки при пересборке.

После замены сцена побайтно совпадает с сохранённой копией до замены: положения, масштаб, повороты, коллайдеры и камера не изменились. Пройдены 320 проверок границ и проверка цепочки отражений.

У танка 56_3036.png прозрачность пересобрана по исходному атласу: старая маска низкого разрешения больше не используется. Для танка включены mipmaps и Trilinear, остальные текстуры сохраняют Bilinear без mipmaps. Размер PNG 896×880, PPU=400, размеры спрайта и коллайдер не изменились. Проверка импорта и сборка Windows завершились успешно.

Стрельба первого уровня: WASD/стрелки перемещают корпус; башня отдельно поворачивается к мыши; одно нажатие ЛКМ выпускает один шар. Курсор скрыт при игре, возвращается в паузе и после выхода из сцены. Шар пока использует существующий Circle.png без эффектов. Спрайт заменяется в Player Tank → FirstLevelTankAim → Projectile Sprite. Корпус и башня — PlayerBody.png и PlayerTurret.png, извлечённые раздельно из исходного атласа Figma с прежней плотностью и качеством.

Красное зеркало отражает и заряжает шар (временно красный цвет, урон 2 вместо 1, пробивает щит); синее отражает и сохраняет заряд. Стены и препятствия уничтожают шар. До пяти отражений, жизнь шара 8 секунд. Враги не добавлены; FirstLevelShotTarget подготовлен для здоровья и щитов будущих врагов. Шары очищаются при переходе между комнатами. Проверка Bounce Club/Verify First Level Shooting проверяет наведение башни отдельно от корпуса, отражения, заряд, урон, щит и столкновения.

Синие зеркала второй комнаты имеют MirrorRicochetSurface.reflectFromCollider=true: отражение по нормали столкновения с их формой, до стены за зеркалом. Для рассчитанной цепочки третьей комнаты сохранено отражение по настроенной плоскости. Проверка стрельбы отдельно проверяет оба зеркала второй комнаты с выстрелом снаружи их коллайдеров.
