# Bounce Club

**2D-аркада про игрушечные танки, где побеждает точный рикошет.**
Сделано за 4 дня на **FunFlow Game Jam × ТПУ**, вариант «Танчики».

Игрок ведёт заводной танк по комнатам из детских кубиков, конструктора и игрушек. Прямой выстрел почти ничего не делает: чтобы побеждать, нужно отражать шар от цветных зеркал и превращать саму арену в оружие.

- **Движок:** Unity **6000.6.5f1** (Unity 6.6), 2D URP
- **Платформы редактора:** Windows, macOS, Linux
- **Одна попытка:** 2–5 минут на уровень

## Как играть

**Цель:** уничтожить всех роботов в комнате. После этого открывается дверь справа, и можно переходить в следующую комнату. Пройди все комнаты уровня — уровень пройден.

**Главная механика — рикошет от зеркал:**

| Объект | Что делает с шаром |
|---|---|
| 🔵 **Синее зеркало** | Отражает шар по законам рикошета. Помогает обойти укрытие и достать врага за углом |
| 🔴 **Красное зеркало** | Отражает и **заряжает** шар: он становится красным и бьёт сильнее. Только заряженный шар снимает **щит** с врага |
| 🧱 **Обычная стена** | Поглощает шар |
| 📦 **Ломаемый блок** | Трескается от попаданий и разваливается, открывая новые линии огня |

**Важно знать:**
- У танка **4 шара**, потом **перезарядка 1,5 с** (видно на панели внизу справа).
- Свой шар после рикошета **может попасть и в тебя**.
- У игрока **3 сердца**. Когда они заканчиваются, комната начинается заново.
- Пунктир при прицеливании показывает, куда полетит шар.

**Враги:**
- **Чёрный шипастый робот** — обычный стрелок.
- **Красный робот** — крепче обычного: нужно попасть **2 раза**.
- **Робот в синем пузыре** — щитовой: щит снимается только заряженным шаром от красного зеркала.
- **Босс** (последняя комната уровня 3) — стреляет из трёх пушек.

Роботы патрулируют короткие участки, останавливаются, когда видят игрока, и стреляют.

**Результат:** после уровня показывается время прохождения и **звёзды** (1–3) за скорость. Можно переиграть и улучшить результат.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | **W A S D** или **стрелки** |
| Прицел | **Мышь** |
| Выстрел | **Левая кнопка мыши** |
| Пауза (продолжить, заново, меню, громкость) | **Esc** |

В главном меню есть **«Настройки»**: громкость звука, музыки и чувствительность мыши.
В окне выбора уровня есть **мирный режим**: враги не стреляют. Удобно, чтобы спокойно изучить комнаты.

## Уровни и рост сложности

| Уровень | Комнат | Что нового |
|---|---|---|
| **1. Детская** | 3 | Движение, стрельба, первые синие и красные зеркала, первый щитовой враг |
| **2. Мастерская** | 4 | Больше врагов, конвейеры-укрытия, цепочки из нескольких зеркал, патрулирующие роботы |
| **3. Замок** | 5 | Ломаемые блоки, плотные комнаты, щитовые враги за укрытиями, **финальный босс** |

Уровни открываются по порядку: следующий доступен после прохождения предыдущего.

## Запуск с нуля

### 1. Что установить

1. **Unity Hub**: <https://unity.com/download>
2. **Unity 6000.6.5f1**. В Unity Hub: **Installs → Install Editor**, найдите **6000.6.5f1**. Если версии нет в списке, откройте вкладку **Archive** или <https://unity.com/releases/editor/archive>.
   > Нужна **именно эта версия**. С другой Unity предложит конвертировать проект.
3. **Git**: <https://git-scm.com/downloads>
4. **Git LFS**: <https://git-lfs.com>
   - **Windows:** уже входит в установщик Git for Windows.
   - **macOS:** `brew install git-lfs`
   - **Linux:** `sudo apt install git-lfs` / `sudo pacman -S git-lfs` / `sudo dnf install git-lfs`

### 2. Скачать проект

Откройте терминал (на Windows — **Git Bash**) и выполните:

```bash
git lfs install
git clone https://github.com/Nayee1i/Funflowgamejam2026-2026-10-10_20-01-52.git
cd Funflowgamejam2026-2026-10-10_20-01-52
git lfs pull
```

> ⚠️ **Все картинки и звуки лежат в Git LFS.**
> Если скачать проект кнопкой **Code → Download ZIP** или клонировать без Git LFS, вместо картинок и звуков будут текстовые заглушки по ~130 байт. В Unity это выглядит как **белый экран без текстур и без звука**. Скачивайте только через `git clone` с установленным Git LFS.

Проверить, что всё скачалось, можно так: файл `Assets/Sprites/HeartIcon.png` должен весить несколько килобайт, а не ~130 байт.

### 3. Открыть в Unity

1. **Unity Hub → Projects → Add → Add project from disk**, выберите папку `Funflowgamejam2026-2026-10-10_20-01-52`.
2. Откройте проект. **Первый запуск занимает 5–15 минут**: Unity импортирует ассеты.
3. Если Unity предложит **Safe Mode**, нажмите **Ignore**. Если предложит сменить версию редактора, нажмите **Cancel** и установите 6000.6.5f1.

### 4. Запустить игру

1. В окне **Project** откройте `Assets/Scenes/` и дважды кликните **`MainMenu`**.
2. Нажмите **▶ Play** вверху по центру.
3. Кликните по окну **Game**, чтобы оно получило управление.
4. **Играть → Уровень 1.**

### Обновить проект позже

```bash
git pull
git lfs pull
```

## Если что-то пошло не так

| Проблема | Решение |
|---|---|
| **Белый экран, нет текстур, нет звука** | Не скачались файлы из LFS. В папке проекта: `git lfs install`, затем `git lfs pull`, после этого вернитесь в Unity |
| **Unity предлагает обновить или конвертировать проект** | Открыта не та версия. Нужна **6000.6.5f1** |
| **Красные ошибки в Console сразу после открытия** | Дождитесь конца импорта (значок внизу справа), затем **Assets → Refresh** (Ctrl+R / Cmd+R) |
| **Клавиши не работают** | Кликните мышью по окну **Game** |
| **Уровни 2 и 3 закрыты** | Так задумано: они открываются по порядку. Сбросить прогресс: **Edit → Clear All PlayerPrefs** |
| **Враги не стреляют** | Включён мирный режим. Выключите его в окне выбора уровня |
| **Нет звука** | **Настройки** в меню: деления «Звук» и «Музыка». Проверьте кнопку **Mute Audio** 🔇 вверху окна Game |

## Звук

Звук подключается без правки сцен:

- **`GameAudio`** запускается сам при старте игры и работает во всех сценах. Он включает музыку по уровню (в последней комнате уровня 3 — музыку босса), озвучивает наведение и клик по любой кнопке и звук мотора танка (стоит или едет).
- **`Assets/Resources/Audio/SoundLibrary`** — громкость каждого звука и громкость для 1/2/3 делений в настройках. Правится в Inspector.
- **Файлы** лежат в `Assets/Resources/Audio/` под именами событий: `shot`, `bounce`, `charge`, `wall_hit`, `enemy_hit`, `enemy_die` и т.д. Чтобы заменить звук, достаточно заменить файл с тем же именем.
- В игровом коде звук вызывается одной строкой: `GameAudio.Play("shot");`
