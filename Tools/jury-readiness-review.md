## Несоответствия и риски
1. Ссылка origin при анонимном запросе GitHub API возвращает 404. Публичность и возможность скачать проект жюри не подтверждены. Возможные причины: приватный, переименованный или удалённый репозиторий. Не установлена точная причина.
2. До указания пользователя не трогать Git были обнаружены незакоммиченные актуальные скрипты/сцены, в том числе FirstRoomTankEffects.cs, на который ссылается изменённый FirstLevelRooms.cs. Рабочая папка и сданная версия могут различаться. Коммиты, пуши и изменения веток не выполнялись.
3. Assets/Audio пустая; игровых AudioSource/AudioClip/PlayOneShot в Assets/Scripts не найдено. Звук не подключён. Настройка музыки сохраняется и рисует шкалу, но не управляет отдельным музыкальным источником.
4. Доступная из меню TankArena — ранний прототип с отдельной системой управления/стрельбы. Волны, бонусы и завершённая сессия арены не реализованы. Требования жюри не обязывают иметь арену; однако открытая незавершённая кнопка ухудшает впечатление.
5. TankArena_README описывает старую первую сцену, старые зеркала и старую стрельбу. Для передачи проекта нужен актуальный README с Unity 6000.6.5f1, MainMenu и управлением.
