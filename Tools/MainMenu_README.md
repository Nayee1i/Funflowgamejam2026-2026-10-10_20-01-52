# Главное меню из Figma

Открыть Assets/Scenes/MainMenu.unity и нажать Play. Сцена первая в Build Settings.

Графика главного меню, настроек и подтверждения выхода экспортирована напрямую из Figma. Макет 1920×1080 сохраняет пропорции на любых экранах. Все элементы находятся в Canvas и доступны для редактирования.

Настройки открывают плашку звука и музыки. Кнопки плюс/минус меняют три ступени индикаторов и сохраняют значения в PlayerPrefs (Menu.SoundLevel, Menu.MusicLevel). Звук управляет AudioListener.volume. Музыка пока сохраняет значение для последующего подключения музыкального AudioSource; музыка в меню отсутствует.

Выход открывает подтверждение: Да закрывает приложение, а в редакторе останавливает Play Mode; Нет и крестик возвращают в меню. Escape закрывает открытое окно. Плашки блокируют клики по нижнему меню. Новые кнопки без эффектов и анимации. Ранее согласованное наведение на главных трёх кнопках сохранено: текст светлеет и увеличивается на 6%, без обводки. Играть остаётся заглушкой.

Assets/UI/MainMenu/ModalLayout.json хранит размеры экспортированных слоёв. Bounce Club → Rebuild Figma Main Menu пересоздаёт сцену из экспортов и сбрасывает ручные изменения её объектов. Использовать вне Play Mode. Другие игровые сцены сохранены.

Токен Figma в проекте не хранится.
После Играть открывается плашка выбора: первая кнопка уровня, две заблокированные кнопки и арена (Бесконечный режим). Крестик и Escape возвращают в меню. Запуск уровней и арены пока не подключён; новые кнопки без эффектов.
Доступная кнопка уровня плавно увеличивается на 6% за 0.12 секунды при наведении и возвращается к исходному размеру при уходе мыши. Цвет не меняется, кнопки с замками неподвижны.
Кнопка бесконечного режима с короной также плавно увеличивается на 6% при наведении.
