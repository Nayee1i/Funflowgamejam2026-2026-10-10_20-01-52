# Инструменты разработки

Игровые сцены и код находятся в Assets. Для запуска и актуальных правил игры смотрите README.md в корне проекта.

Здесь сохранены генераторы карт, геометрия и исходные данные макетов, вспомогательные проверки и исторические заметки разработки. Они не являются дополнительными игровыми сценами и не выполняются при запуске EXE.

Финальные результаты проверки сдаваемой версии:
- submission-preparation-result.txt — новый профиль, открытие уровней, зеркала и попадания.
- submission-campaign-runtime.txt — проверки Play Mode, переходов, патрулей, победы и поражения.
- submission-player-progression-test.txt — тест логики сохранений сборки с имитацией API PlayerPrefs.
- submission-windows-build.txt — результат Windows-сборки.

Старые промежуточные отчёты и локальные номера процессов исключены из репозитория. Код инструментов и игровые ресурсы сохранены.
